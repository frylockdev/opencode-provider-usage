# OpenAI Usage for OpenCode

Компактная панель лимитов подписки OpenAI в правой колонке **OpenCode V2**.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![OpenCode](https://img.shields.io/badge/OpenCode-2.2.6-8b5cf6)](https://opencode.ai)

```text
Usage
OpenAI ●
Pro Lite · через Codex

Неделя
73% осталось
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
27% использовано
Сброс: 2д 5ч

▸ Данные аккаунта
↻ 0м назад · каждые 60с
```

Значения в примере демонстрационные. В терминале использованная часть полосы выделяется цветом.

- Использованный и оставшийся процент, цветная полоса, время до сброса.
- Основные окна сразу; дополнительные квоты, тариф, кредиты, бюджет и доступные сбросы — в подробностях.
- Цвета текущей темы, предупреждение от 80%, красный от 95% использования.
- Обновление раз в минуту при открытой панели; при ошибке — явная отметка устаревших данных.

## Установка

Проверено с OpenCode **2.2.6** и Codex CLI **0.166.0** на macOS.

1. Установите [OpenCode](https://opencode.ai) и [Codex CLI](https://developers.openai.com/codex/cli).
2. Войдите в нужный аккаунт ChatGPT через Codex:

```sh
codex login
codex login status
```

3. Установите плагин глобально из GitHub:

```sh
opencode plugin add 'github:frylockdev/opencode-provider-usage#v0.1.3'
```

OpenCode подхватит настройку автоматически. Если панель не появилась — `/reload`.
Откройте сессию с видимой правой панелью. `codex` должен быть доступен в PATH **серверного**
процесса OpenCode. При удалённом сервере используется его установка и аккаунт Codex.

### Локальная разработка

```sh
git clone https://github.com/frylockdev/opencode-provider-usage.git
cd opencode-provider-usage
npm ci
npm exec --yes --package=bun -- bun run build:tui
```

Для работы с исходниками добавьте абсолютный путь в `~/.config/opencode/opencode.json`:

```json
{
  "plugins": ["/absolute/path/to/opencode-provider-usage"]
}
```

Используйте одну запись плагина: GitHub-пакет или локальный каталог.
После изменений интерфейса повторяйте сборку. `dist/tui.js` включён в GitHub-релиз:
установленному плагину Bun отдельно не нужен. Загрузчик OpenTUI не компилирует TSX внутри `node_modules`.
Команда названа `build:tui`, чтобы npm не запускал лишнюю подготовку Git-зависимости при установке.

## Управление

- Нажмите **Данные аккаунта** — раскрыть или свернуть подробности.
- `/usage` или Ctrl+P → **OpenAI Usage: подробности** — тот же переключатель с клавиатуры.
- Нажмите строку **↻** или Ctrl+P → **OpenAI Usage: обновить**.
- Ручное обновление соблюдает минутный кеш и паузу после ограничения запросов.

## Источник и ограничения

Данные приходят из официального локального `codex app-server`: только `account/read` и
`account/rateLimits/read`. Плагин не запускает генерацию и не читает файлы токенов.
Авторизацией и обновлением токенов управляет Codex.

**Показывается аккаунт, выбранный в Codex**, а не автоматически аккаунт OpenCode. Его адрес и
workspace видны в подробностях, источник «через Codex» — всегда. Выберите тот же аккаунт,
если хотите следить за используемой в OpenCode подпиской. Изменение входа обнаруживается при
следующем обновлении (до 60 секунд).

Текущий вход OpenCode через ChatGPT token-sharing не предоставляет API остатков:
прямой запрос `wham/usage` возвращает HTTP 401. См. [openai/codex#54219](https://github.com/openai/codex/issues/54219).
Поэтому плагин использует отдельный вход Codex для чтения лимитов.

Показываются только поля, которые вернул Codex. Нет данных ≠ 0% использования.
Кредиты не обозначаются долларами. Даты показываются в местном часовом поясе терминала.
Доступные сбросы только отображаются; плагин их не расходует.

При невозможности определить аккаунт предыдущие показатели удаляются. При временной ошибке
после определения того же аккаунта сохраняется последний результат с отметкой устаревания.
Таймаут запроса — 15 секунд. Codex RPC не передаёт HTTP Retry-After: при сообщении о rate limit
плагин делает паузу 5 минут. При скрытой панели polling останавливается.

## Проверки

```sh
npm test
npm run typecheck
npm exec --yes --package=bun -- bun run build:tui
npm exec --yes --package=bun -- bun run test:tui
opencode plugin list
opencode api post /api/rpc/openai-usage/get --data '{"input":{}}'
```

Последняя команда выводит показатели и метку аккаунта, без credentials.
Renderer-тест использует Bun, необходимый OpenTUI. Сам плагин запускается в runtime OpenCode.

## Удаление

```sh
opencode plugin remove 'github:frylockdev/opencode-provider-usage#v0.1.3'
```

При локальной установке уберите путь плагина из глобального `plugins`.
